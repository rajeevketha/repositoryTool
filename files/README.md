# Download OrgFlow (Chrome extension zip)

**Direct download:** [orgflow-extension.zip](./orgflow-extension.zip)

Unzip it. You should get an `orgflow/` folder that contains `manifest.json`.

## Load in Chrome

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. **Load unpacked** → select the unzipped `orgflow` folder
4. Pin OrgFlow and open the side panel. Use **Workbench** for the wide picker.

Chrome cannot load the `.zip` itself. Always load the unpacked folder.
