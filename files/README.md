# Download OrgFlow

## Load unpacked (local test)

https://raw.githubusercontent.com/rajeevketha/repositoryTool/cursor/orgflow-salesforce-deploy-c0ed/files/orgflow-extension.zip

Unzip → `orgflow/` folder with `manifest.json` inside it.

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. **Load unpacked** → select the unzipped `orgflow` folder
4. Pin OrgFlow and open the side panel

Chrome cannot load the `.zip` itself.

## Chrome Web Store upload

Upload **`orgflow-chrome-web-store.zip`** (same folder). `manifest.json` is at the **root** of that zip. Follow `docs/chrome-web-store.md`.
