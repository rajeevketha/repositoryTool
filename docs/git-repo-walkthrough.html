Local snapshots stays the default. Connect a host only when the team needs one history.

4 · Same ticket again

Save once more → v2

Change members or files, retrieve, save with a new commit message. OrgFlow keeps v1 and adds PROJ-123-v2.

You can still deploy v1 to an org that should not get the later change.

What a team repo can do

The full Git loop

  • Connect GitHub, GitLab, or Azure
  • Save pipelines and Jira versions (v1, v2, …)
  • Compare / diff metadata and Apex
  • Revert selected files into the current retrieve
  • Deploy a saved version to the next org

Token stays in this Chrome profile. Review files in the Git host like any other commit.
