    Connect GitHub

    Needed only for Git version control. The token stays in this browser. It is never committed to the repo.

    How to create a GitHub token
    1. Open github.com/settings/tokens while signed into GitHub.
    2. Click Generate new token. Classic tokens need the repo scope. Fine-grained tokens need Contents: Read and write on the repo you will use.
    3. Copy the token (it starts with ghp_ or github_pat_) and paste it below.
    4. Click Connect GitHub, pick owner/repo (or paste it), then Use this repo.
